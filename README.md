# 👨‍💻 Todo app

A To-Do List app built using **React**, **Redux Toolkit**, **TypeScript**, and **TailwindCSS**, allowing users to create, update, and manage their tasks with ease.

## ✨ Features

- 📑 **Task Management** Create, read, update, and delete tasks with ease
- 🧠 **State Management** with Redux Toolkit
- 🎨 **Simple Modern UI** with Tailwind CSS
- 💾 **Persistent Storage** (tasks saved in localStorage)
- ✅ **Form Validation powered** by Zod and React Hook Form
- 🔍 **Search tasks** Quickly find tasks by title, owner, or assignee
- 📑 **Pagination** Navigate through large task lists efficiently

```bash
git clone https://github.com/IGBagusAryaN/todo-list-app.git

```
